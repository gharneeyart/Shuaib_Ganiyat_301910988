# Advanced Database Systems Portfolio (MIT 8103)

**Shuaib Ganiyat, 301910988** · Miva Open University, 2026/2027 first semester CA

For this course I built five portfolios around one case study: **Adetwin Stores**, a small retail and wholesale shop that sells foodstuff and household goods. The database handles its sales, payments and stock. PostgreSQL (Neon) is the main database, and MongoDB (Atlas) is used for the NoSQL part.

Each portfolio has its own README that explains what was done and how to run it.
